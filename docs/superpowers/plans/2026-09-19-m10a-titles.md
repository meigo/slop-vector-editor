# M10a — Titles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Place a title on the canvas, type it, choose its font, size, spacing and alignment, and
have it save and reload as an ordinary path that remembers it was text.

**Architecture:** A title is a `PathShape` with optional `text` metadata — not a new node kind, so
the 23 places that test `kind === "path"` keep working unchanged. `opentype.js` sits behind a lazy
chunk (the pattern M7 established for Paper) in one module, `src/text/font.ts`; everything else
sees plain `Subpath[]`. Layout and the attribute format are pure and unit-tested.

**Tech Stack:** TypeScript strict, Svelte 5 runes, Vitest (node, **no DOM**), `opentype.js` 2.0,
four SIL OFL fonts imported through Vite as `?url` assets.

**Spec:** `docs/superpowers/specs/2026-09-19-m10-artistic-text-design.md` (§10 splits delivery;
this plan is M10a. `seed`, `amounts` and `overrides` are carried in the model and the attributes
from the start, at identity values, so M10b adds no format change.)

## Global Constraints

- **The document is immutable** (invariant 1); a no-op edit returns the same reference.
- **Node/Vitest has no DOM.** Pure modules only in tests; never import a `.svelte` file.
- **TypeScript strict**, `verbatimModuleSyntax`, `erasableSyntaxOnly`. **Build bar: 0 errors, 0 warnings.**
- **Canvas and export share `src/svg/attrs.ts`** (invariant 3).
- **`opentype.js` may be imported by `src/text/font.ts` and nowhere else**, and only through
  `await import(...)`, so it stays a lazy chunk. Its ESM export is a **default object**:
  `const ot = (await import("opentype.js")).default;` then `ot.parse(buf)`. `import * as ot` does
  **not** work — the namespace has no `parse`.
- **Never put fonts in `public/`** (invariant 35). Import them with Vite's `?url` so they are
  content-hashed into `dist/assets/`.
- **Every `title` is also a status-bar hint** (invariant 24), written as an action phrase;
  unavailable controls use `aria-disabled` with a reason.
- **Store actions that edit the document call `cancelActiveGesture()` first** (invariant 15).

### Task 1: The pure pieces — layout and the attribute format

**Files:** Create `src/text/layout.ts`, `src/text/attrs.ts`; Test `src/__tests__/text-pure.test.ts`

**Produces:**
`type Align = "left" | "center" | "right"`;
`type CharOverride = { r?: number; s?: number; dx?: number; dy?: number; k?: number }`;
`type TextMeta` (per spec §3);
`layoutRun(advances: readonly number[], kerns: readonly number[], size: number, letterSpacing: number, align: Align): { pen: number[]; width: number }`;
`formatTextOpts(m: TextMeta): string` / `parseTextOpts(s: string): Pick<TextMeta,"size"|"letterSpacing"|"align"|"seed"|"amounts"> | null`;
`formatOverrides(o: Record<number, CharOverride>): string` / `parseOverrides(s: string, length: number): Record<number, CharOverride>`.

- [ ] **Step 1: Write the failing test** — `src/__tests__/text-pure.test.ts`. Cover:
  - `layoutRun` with advances `[10,20,10]`, no kerning, size 1, spacing 0 → pen `[0,10,30]`, width 40.
  - kerning applied between pairs (negative kern pulls the next pen back).
  - `letterSpacing` added after every character except the last, so the width does not gain a
    trailing gap.
  - `align`: `left` leaves pen at 0, `center` shifts by `-width/2`, `right` by `-width`.
  - the empty run: `pen: []`, `width: 0`.
  - `formatTextOpts`/`parseTextOpts` round-trip; `parseTextOpts` returns `null` for the wrong field
    count, a non-finite number, and an unknown align keyword.
  - `formatOverrides`/`parseOverrides` round-trip for `{3:{r:-12,s:1.2},7:{dx:4}}` →
    `"3:r=-12,s=1.2;7:dx=4"`; empty map → `""`; `parseOverrides` drops an index `>= length`,
    a negative index, an unknown key and a non-finite value, without throwing.

- [ ] **Step 2: Run it and watch it fail.**

- [ ] **Step 3: Implement both modules.** `layoutRun` walks the advances accumulating
  `pen[i]`, adding `kerns[i]` (the kern *before* character `i`, so `kerns[0]` is 0) and
  `letterSpacing` between characters; `width` is the final pen plus the last advance. Alignment is
  a single shift applied to every pen position. The attribute helpers follow `parsePolygonAttr`'s
  shape in `src/svg/parse.ts`: validate every field, return `null` rather than throw.

- [ ] **Step 4: Tests pass. Step 5: `npm test && npm run build`. Step 6: Commit** —
  `feat: pure text layout and the title attribute format`.

### Task 2: The font pipeline

**Files:** Create `src/text/font.ts`, `src/text/fonts/index.ts`, `src/text/fonts/*.ttf` + `*-OFL.txt`;
Modify `package.json`; Test `src/__tests__/text-outline.test.ts`; Fixture `fixtures/Anton-Regular.ttf`

**Consumes:** `layoutRun` (Task 1).
**Produces:** `BUNDLED: { id: string; label: string; url: string }[]`;
`loadFont(id: string): Promise<LoadedFont>`; `registerFontFile(file: File): Promise<string>`;
`isFontLoaded(id: string): boolean`;
`outlineText(font: LoadedFont, meta: TextMeta): Subpath[]`;
`FONT_EXTS = [".ttf", ".otf", ".woff"]`, `WOFF2_REFUSAL` (the exact string in spec §5).

- [ ] **Step 1: Add the dependency and the fonts.** `npm install opentype.js`. Download four SIL
  OFL faces into `src/text/fonts/` from `https://github.com/google/fonts/raw/main/ofl/<name>/…`,
  each with the `OFL.txt` that sits beside it in that repo, renamed `<face>-OFL.txt`. Pick four
  display faces whose static `-Regular.ttf` is under ~250 KB; record the four chosen and their
  byte sizes in the commit message. `src/text/fonts/index.ts` exports `BUNDLED` with
  `import antonUrl from "./Anton-Regular.ttf?url"` style imports. Add
  `declare module "*.ttf?url"` to `src/vite-env.d.ts` (or the project's ambient types) if the build
  complains.

- [ ] **Step 2: Write the failing test** — `src/__tests__/text-outline.test.ts`, using
  `fixtures/Anton-Regular.ttf` read with `node:fs` (copy the same file there; the test must not
  depend on Vite's `?url`). Assert, per spec §8:
  - `S` outlines to at least one subpath with more than two nodes;
  - `O` yields **two** subpaths — the counter, which nonzero fill draws as a hole;
  - every node arrives as a cubic (no quadratics survive `parsePathData`);
  - a two-character run places the second glyph to the right of the first;
  - `align: "center"` centres the run's bounding box about x = 0 within 1e-6;
  - `size` scales linearly: doubling it doubles the bounding-box width.

- [ ] **Step 3: Run it and watch it fail.**

- [ ] **Step 4: Implement `src/text/font.ts`.**

```ts
/** The only module that may touch opentype.js, and only through a dynamic import, so the parser
 *  stays a lazy chunk (spec M10 §2 — 67.7 KB gzipped, measured). */
let otPromise: Promise<typeof import("opentype.js").default> | null = null;

async function ot() {
  if (!otPromise) {
    otPromise = import("opentype.js")
      .then((m) => m.default)
      .catch((e) => {
        otPromise = null; // a failed fetch must not be replayed from cache (M7's rule)
        throw e;
      });
  }
  return otPromise;
}
```

  `loadFont(id)` resolves the id against `BUNDLED` then the session registry, fetches the bytes
  once, parses, and caches the `LoadedFont` (`{ id, label, font }`). `registerFontFile(file)` reads
  the `File` as an `ArrayBuffer`, **refuses `.woff2` before parsing** with `WOFF2_REFUSAL`, parses,
  derives the label from `font.names.windows?.fontFamily?.en ?? font.names.macintosh?.fontFamily?.en
  ?? file.name` (the spike found `font.names.fontFamily` is `undefined`), and stores it in a
  module-level `Map` for the session.

  `outlineText(font, meta)` is the pipeline: `font.stringToGlyphs(meta.text)` → advances scaled by
  `size / unitsPerEm` → `font.getKerningValue(prev, cur)` per pair → `layoutRun` → for each
  character `font.getPath(char, pen[i], 0, meta.size).toPathData(3)` → `parsePathData()` from
  `src/svg/pathdata.ts` → concatenate the subpaths. **M10a applies no per-character transform**;
  `meta.seed`, `meta.amounts` and `meta.overrides` are carried but unused, and M10b adds the
  transform step here.

- [ ] **Step 5: `npm test && npm run build`.** The build must now show **three** chunks; record the
  opentype chunk's gzipped size and confirm the app's own chunk is within ~1 KB of 74.3 KB.

- [ ] **Step 6: Commit** — `feat: the font pipeline, behind a lazy chunk`.

### Task 4: The Text tool and the panel

**Files:** Create `src/tools/text-tool.ts`, `src/lib/TextPanel.svelte`; Modify
`src/tools/registry.ts`, `src/tools/types.ts`, `src/state/appState.svelte.ts`,
`src/state/keys.ts`, `src/lib/ToolStrip.svelte`, `src/lib/PropertiesPanel.svelte`

**Consumes:** everything above.
**Produces:** `ToolId` gains `"text"`; store actions `placeTitle(p: Vec)`, `setTitleText(s: string)`,
`setTitleFont(id: string)`, `setTitleOpts(patch)`, `addFontFile(file: File)`.

- [ ] **Step 1: The tool.** `createTextTool()` follows `shape-tools.ts`'s shape: on pointer-up of a
  click that did not drag, it calls `ctx` to place a title at the document point. It holds no
  draft — unlike the pen, a title is created in one step, so nothing needs invariant 33's treatment.

- [ ] **Step 2: The store actions.** Each calls `cancelActiveGesture()` first, then commits one
  undo step. `placeTitle` loads the current font (awaiting the lazy chunk), outlines `Title`, and
  inserts a path with `text` into the current layer, honouring `blockMessage` for a hidden or
  locked layer exactly as the shape tools do. Editing actions re-outline and replace the subpaths.
  Because loading is async, they follow M7's rule: capture the document before awaiting, and refuse
  to commit if the document or selection moved meanwhile; a failed font load raises an **error**
  notice, not an info.

- [ ] **Step 3: The panel.** `TextPanel.svelte` renders the Text section from spec §6 — the string
  field, the font select with its *Add a font…* button, and size, spacing and alignment. It is shown
  by `PropertiesPanel.svelte` when the selection is exactly one path with `text`. The string field
  and the font select are `aria-disabled` with the missing-font reason when
  `!isFontLoaded(meta.font)`. `Add a font…` uses a hidden `<input type="file">` with
  `accept=".ttf,.otf,.woff"`; a `.woff2` still reaching it raises the refusal notice.

- [ ] **Step 4: Wire the tool** into `TOOLS`, the tool strip (a `Type` icon from `@lucide/svelte`)
  and the `T` shortcut in `src/state/keys.ts`. Check `T` is not already taken.

- [ ] **Step 5: `npm test && npm run build`. Step 6: Commit** — `feat: the Text tool and its panel`.
