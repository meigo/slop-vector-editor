## High

### ✅ fixed (batch 1) H1 — A still finger/Pencil for 500 ms kills the stroke or drag in every tool without a menu *(area 1)*
- **Where:** `src/lib/Canvas.svelte` long-press callback (~76-89) and its arming (~295-298);
  `openContextMenu` refuses tools other than Select/Node (`appState.svelte.ts` ~1504).
- **Scenario:** Brush with the Pencil: press to start a careful stroke, or draw small detail that
  stays within 10 screen px for half a second → the long press fires, **cancels the tool gesture
  first**, then finds no menu for the Brush. The preview vanishes and nothing commits — ink lost.
  Same for shapes (press, hesitate, drag → nothing), the Pen (place, pause, pull handle → no
  curve), Gradient/Warp knob drags that start with a pause, Text drag-select. Mouse unaffected.
- **Fix:** arm the long press only when a menu can open (Select/Node), or check before cancelling.

### ✅ fixed (batch 2) H2 — Common SVG properties are silently ignored, and the save-in-place handle is kept *(area 5)*
- **Where:** `src/svg/parse.ts` `PROPS` (~67); handle rule `project-io.ts` ~60.
- **Scenario:** `fill-rule="evenodd"` (on nearly every Figma/Sketch icon), `stroke-dasharray`,
  markers (arrowheads), `transform-origin`, CSS `transform` in `style` → imported with
  `dropped: []`: holes fill in, dashes go solid, arrows vanish, no notice. For our own file edited
  in Inkscape (dash or even-odd added), `native && dropped.length === 0` keeps the handle, so ⌘S
  **overwrites the file without them** — breaks invariants 4 and 10.
- **Fix:** report non-default values of the properties the model can't represent (`drop(...)`),
  which also releases the handle.

## Medium

### Input & touch
- ✅ fixed (batch 1) **M1 ×2 — Switching tools mid-stroke throws the brush stroke away** (areas 1, 3). A Canvas
  `$effect` on `app.toolId` cancels any running tool gesture; the brush's `cancel` drops the stroke.
  CLAUDE.md invariant 48 and M21 ruling 2 say it lands. Fix: skip the cancel for a running brush
  gesture, or correct the docs (and drop the now-dead `gestureTool` reasoning).
- ✅ fixed (batch 1) **M2 — Hiding the dock leaves a latched (or held) Shift/Alt active and invisible.**
  `ModifierDock.svelte` `toggleExpanded` only writes the pref; `app.dock` stays latched → every
  Select drag duplicates (Alt), corners stretch / moves snap 45° (Shift). A held key whose button
  unmounts stays "held" until reload. Fix: reset both keys when collapsing.
- **M3 — The first finger of a pinch or two-finger tap acts irreversibly in Pen, Text and an
  entered group** (only before the Pencil has been seen: finger-only devices, or before first
  Pencil use). Pen: a stray node is added (pen's cancel keeps the draft); Text: a pinch ends or
  switches the edit session; Select: leaves the entered group. Fix: have `pen.cancel` remove the
  node its cancelled press added, and similar undo for the other two, or defer `down` for touch.

### Text & editing session
- ✅ fixed (batch 2) **M4 ×2 — A title over 2000 characters saves but reopens as a plain path** (areas 2, 5). The
  importer caps `MAX_TEXT_LENGTH` (`parse.ts` ~483, `text/attrs.ts` 32) but nothing in the editor
  does; `dropped` is empty so the handle is kept too. Fix: refuse over the cap in `reshapeTitle`
  (quiet while typing, notice on commit).
- ✅ fixed (batch 3) **M5 — An override moves to the wrong twin next to a doubled letter** ("Tallinn": delete the
  jittered first "l" → the second "l" becomes jittered). Accepted as a spec ambiguity in M22
  Task 1; the reviewer's fix removes it: pass the caret position into `editSpan` from
  `typeTextEdit` (and `selectionStart` from the panel field).
- ✅ fixed (batch 3) **M6 — A face that can't load raises an error notice on every "quiet" keystroke, and the session
  shows no caret.** `withFont` always notifies; `reshapeTitle` doesn't pass `quiet`. Offline + an
  uncached Google weight → one error per keystroke. Fix: thread `quiet` through `withFont`.
- ✅ fixed (batch 3) **M8 — A queued title patch commits on top of an undo, wiping redo** (area 4). A reshape in flight
  on a slow load is dropped when the user undoes, but a queued patch is not — it commits onto the
  undone document. Fix: discard the queue when the in-flight reshape is dropped for a moved doc.
- ✅ fixed (batch 3) **M9 ×2 — `placeTitle` holds `titleRunning` without draining the queue** (areas 2, 4). A panel
  edit to the selected title while a new title's font loads is lost silently, or (if placing fails)
  applied later over a newer edit. Fix: run placement through the same drain (`titleWork`).

### Undo & integrity
- ✅ fixed (batch 1) **M7 — Document settings Apply doesn't settle the Warp tool; the next cage drag reverts the
  artboard** (`DocumentSettingsDialog.svelte` ~20-24 is the only `commitDoc` outside the store that
  skips `cancelActiveGesture`). Fix: a store action `setArtboardSize` that cancels first.
- ✅ fixed (batch 1) **M19 ×2 — Layers panel drops into a locked or hidden group** (areas 3, 8). `dropTarget` and
  `moveNodesTo` check only the layer; the object becomes locked/invisible content and drops out of
  the selection. Fix: refuse when `blocked(doc, parentId)`.

### Async & persistence
- ✅ fixed (batch 2) **M10 ×2 — An autosave that fails to parse is overwritten by the empty startup document 3 s
  later** (areas 4, 7). `restoreAutosave` notifies and still returns `true`, so autosave resumes and
  writes the blank document over the only copy. Fix: return false (autosave off for the session),
  or copy the record aside first.
- **M18 — The sidebar's viewport clamp is saved**, so rotating an iPad to portrait and back
  permanently shrinks a chosen width (500 → 410 → 410). Fix: clamp for display only; write the pref
  only on a drag release (as the split already does).

### File round-trip
- ✅ fixed (batch 2) **M11 — In our own format, a layer's `transform` and `opacity` are discarded**, handle kept
  (Inkscape writes layer opacity) → ⌘S writes it back without them. Fix: wrap as the foreign path
  does, or report.
- ✅ fixed (batch 2) **M12 — Import/drop/paste merges source layers so hidden layers appear and locked ones unlock**
  (`clipboard.ts` ~93). Fix: mark children of hidden/locked source layers `hidden`/`locked`, or
  leave hidden layers out and report them.
- **M13 — Illustrator/draw.io `<switch>` files import empty** (reported, but a browser renders the
  `<g>` fallback). Fix: treat `<switch>` as a group rendering its first valid child.

### Geometry
- **M14 — A uniform corner drag on a thin object is ruled by its short axis**: a 200×2 line's corner
  moved 5,3 px becomes 500 long (k = max of ratios). New default since today's uniform corners;
  finger jitter makes it easy to hit. Fix: take k from the pointer projected on the box diagonal.
- **M15 — Node-tool snapping aligns the pointer, not the node**: guide at x=70, node lands at 66
  (off by the grab offset, up to 10 px on touch). Fix: snap `pointer + grab`.
- **M16 — Gradient tool: drag out and back to the start turns the fill transparent** (degenerate
  line → end stop at opacity 0; a gradient is lost and its memory forgotten). Fix: treat a
  degenerate draw as "no line" and commit the base.
- **M17 — Flatten transform bakes a scale into the geometry but keeps `strokeWidth`**, so an imported
  `scale(2)` path's stroke visibly halves (also Combine/Boolean's frontmost operand). Fix: scale
  the stroke width by √|det| for a uniform scale; refuse or bake only rotate/translate otherwise.

### UI & keyboard
- ✅ fixed (batch 1) **M20 — ⌘S/⌘O inside any panel text field open the browser's Save Page / Open File** (App's
  handler skips editable targets entirely; the canvas field was fixed, the panel fields weren't).
- ✅ fixed (batch 1) **M21 — After using a slider, colour swatch or select, every app shortcut is dead** (⌘Z, ⌫, tool
  keys) until focus moves — `isEditable` treats every INPUT type and SELECT as a text field. Fix:
  filter by input type (`NON_TEXT_INPUT_TYPES` already exists) and route mod-key commands.
- ✅ fixed (batch 1) **M22 — The sidebar grip's arrow keys also nudge the selection** (the keydown bubbles to the
  window handler as a nudge). Fix: `stopPropagation` in `gripKey`.
- **M23 — Fill/Stroke "On" on a mixed selection repaints every shape with the default** (a red or
  gradient fill is replaced). Fix: fill only the `null` slots.

## Unverified suspicions (not proven; worth a look when nearby)
- Text: the reused textarea's native undo stack might cross sessions in WebKit (⌘Z restoring the
  previous title's text); placing + typing is two undo steps (a design question); IME composition
  text is outlined live; code points vs grapheme clusters for combining marks and ZWJ emoji.
- Undo: an undo during a UI bracket (NumberField drag, colour picker) closes it and later live
  values become separate steps; a resumed pen draft keeps stale matrices if the path is nudged; two
  quick TextPanel NumberField drags can share a bracket.
- Async: the startup restore could replace work done in its first milliseconds; the Google Fonts
  cache stores bytes before they are known to parse (a proxy page cached forever); a pending brush
  stroke landing while the Open picker is up is replaced without asking.
- Files: non-ASCII element names fail with `XmlError`; DTD entities in `style` ignored; a root
  `opacity` ignored unreported.
- Geometry: a perfect-freehand spike or a warp could leave a closed subpath's last node on its
  first (invariant 30) in rare shapes; hit tolerance under non-uniform imported scales is
  approximate.
- Persistence: Safari can lose the IndexedDB connection without `onclose`, leaving autosave dead for
  the session (reset `dbPromise` on a write failure); a `pagehide` write may not land on iOS;
  manifest has no 192/512 PNG icons (Chrome install).
- UI: the Midpoint % field may clip "50"; the TextPanel's async "Download" button moves the rows
  below it (invariant 23); two Sidebar instances are always mounted.
